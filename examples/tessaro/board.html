One line

The same theme contract in HTML, CSS or React. Change a token, rebuild, and every variant follows.

What is in the folder

Fifteen SVG variants, a favicon, two app icons, tokens, palette CSS, a control-sheet preview and a typed React component. The alternate palette is built from the same masters.
